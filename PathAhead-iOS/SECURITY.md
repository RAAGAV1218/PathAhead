# Security policy

PathAhead is a hackathon prototype and is not designed for security-sensitive or safety-critical deployment. Bluetooth telemetry is not authenticated or encrypted by this firmware. Do not use a shared ElevenLabs key; the personal prototype expects the owner’s own key in the iPhone Keychain.

Please do not post API keys, certificates, personal data, or an unpatched security issue in a public issue. If GitHub private vulnerability reporting is enabled for this repository, use it. Otherwise, contact the repository owner privately before sharing details.

There is no production support or guaranteed response time. Security reports are welcome, but do not rely on this prototype for personal safety.
